# batsman_analysis
Use this to know about the batsman career stats about his dismissal types and his boundaries scored.

1. generate_data.py is used to create a suitable dataset for our program to read. When initialised, it will generate a dataset of a batsman about his 500 innings.
   It can be edited and used as per requirement of how many innings and what more data we need in it.
2. main.py when used, will show us the dismissal methods of the batsman using bar graph. And further will show the heat map of which bowler dismissed him the most,      and the way he got out.
3. main2.py will present us a wagon wheel showing the the area where the batsman scored the most number of boundaries.
